# Agent mission

Before every task, including a resumed session, read and follow the learning
contract that matches the learner's language: [`docs/PROMPT.md`](docs/PROMPT.md)
for Spanish or [`docs/PROMPT.en.md`](docs/PROMPT.en.md) for English. Read only
one; it must remain in context throughout the conversation.

This repository is **Chapter 1: Installation and Backend**. Chapter 2 covers
Frontend and automated testing; Chapter 3 covers the Harness. Do not expand
into later chapters unless a maintainer explicitly asks.

For maintenance work explicitly requested by a repository maintainer, normal
implementation behavior takes precedence over the learner teaching cadence.
